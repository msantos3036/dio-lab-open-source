# 📊 Da planilha ao dashboard

Automatizando dados financeiros com MySQL, Power BI e Go.

Este repositório acompanha o artigo publicado na DIO sobre organização e análise de dados financeiros utilizando tecnologias modernas.

## 🧠 Contexto

Em muitas empresas os dados financeiros estão espalhados em planilhas, dificultando a análise e a consolidação das informações.

Este artigo apresenta uma abordagem simples para estruturar esses dados utilizando:

- MySQL
- Power BI
- Go (Golang)

## ⚙ Arquitetura da solução

Fluxo de dados utilizado:

Excel → Script Go → MySQL → Dashboard Power BI
