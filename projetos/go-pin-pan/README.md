# Desafio Go - Pin Pan

## Objetivo

Criar um programa em Go que utilize:

- Estrutura `for`
- Operador módulo `%`

## Desafio Parte 1

Exibir todos os números entre **1 e 100** que são divisíveis por **3**.

## Desafio Parte 2

Implementar uma brincadeira:

- Múltiplos de **3** → `Pin`
- Múltiplos de **5** → `Pan`
- Caso contrário → número normal

## Exemplo de saída
1
2
Pin
4
Pan
Pin
7
8
Pin
Pan

## Como executar
go run main.go
